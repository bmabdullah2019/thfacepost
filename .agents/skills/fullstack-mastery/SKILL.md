# Fullstack Mastery Playbook

## Frontend & Mobile
- **React & Component State**: React hooks (`useState`, `useEffect`, `useCallback`, `useMemo`), clean unidirectional data flow.
- **Capacitor Mobile**: Native plugins (`CapacitorHttp`, `SplashScreen`, `Preferences`, `Camera`), adaptive safe-area insets.
- **Responsive Styling**: CSS Grid & Flexbox, hardware-accelerated animations (`transform`, `opacity`), dark/light themes.

## Backend & APIs
- **RESTful API Design**: Semantic HTTP status codes (200, 201, 400, 401, 403, 404, 409, 500), consistent JSON schemas.
- **Authentication & Sessions**: Bearer JWT tokens, session persistence, secure password hashing (`password_hash` with Argon2/Bcrypt).
- **Database Engineering**: MySQL / MariaDB transactions, prepared statements, optimized JOINs and execution plans (`EXPLAIN`).
