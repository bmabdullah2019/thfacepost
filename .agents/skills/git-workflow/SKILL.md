# Git Workflow & Release Automation

## Best Practices
1. **Atomic Commits**: Group related file changes with clear, descriptive commit messages.
2. **Branch Management**: Feature branching (`feature/*`), bugfix branches (`fix/*`), main production branch (`main`).
3. **Clean Synchronization**: Regular fetch, rebase/merge, and verified remote push to GitHub.
4. **Release Asset Packaging**: Automated generation of binary releases (e.g. `.apk`, `.zip`, tarballs).
